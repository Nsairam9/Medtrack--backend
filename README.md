# MedTrack Backend

**MedTrack: Prescription & Medicine Reminder System with Pharmacy Locator**

## Project Description

MedTrack is a backend application developed using Spring Boot and MySQL to manage users, medicines, prescriptions, and reminders while supporting pharmacy locator functionality.

## Technologies Used

- Java
- Spring Boot
- MySQL
- Maven
- REST APIs

## Features

- User registration and login
- Medicine management
- Prescription management
- Medicine reminders
- MySQL database integration
- REST API support for frontend integration
